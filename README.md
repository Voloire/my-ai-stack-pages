# Stack AI locale su 16 GB di VRAM

Questo repository contiene una sola pagina, pubblicata con GitHub Pages:

**https://voloire.github.io/my-ai-stack-pages/**

Racconta la costruzione di un ambiente AI interamente locale, dalla conversazione alla voce
alla trascrizione alle immagini al video, su una GPU consumer da 16 GB: cosa entra davvero
in scheda, quali decisioni sono state prese e perche', e le dieci trappole diagnostiche che
hanno richiesto piu' tempo dell'installazione.

Ogni numero nella pagina è misurato, non stimato.

La configurazione operativa e gli script vivono in un repository separato e privato: qui c'è
soltanto il racconto.
